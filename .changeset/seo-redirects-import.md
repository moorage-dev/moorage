Add the Redirects tab: paste a list exported from Redirection, Yoast SEO Premium or Rank Math (or any old-address, new-address list), check it as a dry run, add it, and remove the batch again. Safe regular expressions become EmDash patterns; the rest are listed for a human. Existing redirects are never changed. The site's redirects can be shown as a copyable list.
