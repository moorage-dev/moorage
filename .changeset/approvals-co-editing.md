Ready for EmDash's co-editing (EmDash 1.5, when a site turns it on): when several people edit a page together, EmDash saves their changes as one save in one person's name. If that save holds someone else's changes too, an approved page now needs approval again, and an approver is no longer named as the only person who changed a page waiting for approval. Without co-editing nothing changes.
