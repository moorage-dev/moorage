Fits a phone, and a box in a page looks the same in the preview as on the page:

- On a phone, the list no longer scrolls sideways or cuts off the Preview button. Each row now has just Edit and Preview, and the status wraps onto a second line when it is long. Turn on or off, Duplicate and Delete moved to the top of a popup's own page (open it with Edit).
- The preview of a box in a page now puts it in the page's text column, lined up with the text as visitors see it. Before, it sat in the middle of the page.
- If your site has its own styles for forms (the Forms plugin's `.ec-form` classes), a form inside a box in a page now uses them. Sites without form styles see no change.
