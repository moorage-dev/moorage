## How do I add schema markup to EmDash?

Install this plugin. Every page gets structured data (JSON-LD) straight away; say who the site is for on the SEO page to make it accurate.

## How do I add structured data to one page?

Add a JSON field named `json_ld` to the collection and paste any schema.org object into the entry. It is added to the page's one graph, and with an `@id` the page names it as its main entity.

## Is there a Yoast alternative for EmDash?

EmDash core covers titles, descriptions, sitemaps and canonicals. This plugin adds the schema graph, page checks, the Google preview and redirects import.

## How do I import redirects from WordPress?

Export them from Redirection, Yoast SEO Premium or Rank Math, open SEO > Redirects > Import from WordPress, paste the list and press "Check list". Nothing is added until you confirm.

## How do I noindex a collection in EmDash?

Open SEO > Settings > Content types and choose "Hide from Google and other search engines" for that content type.

## Does it do title templates or llms.txt?

Not by itself: a plugin cannot set the page title or serve files from the site root. Both are done by the theme.
