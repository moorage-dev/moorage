## Reporting a problem

Email **security@moorage.dev**, not a public issue. Say which version you use, what you found and how to reproduce it. Fixes go into the latest release; update to it to receive them. The source is public on GitHub.

## What it keeps and sends

Each enquiry is stored in the site's own database until all its deliveries are done, then its contents are deleted; log rows are kept for 30 days. Enquiries go only to the addresses, HubSpot forms and apps you enter. Each app delivery is signed with its own secret. Connecting a form in one step uses the admin access you approve once and then throws it away; it is never stored.
