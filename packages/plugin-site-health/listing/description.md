Site Health is a broken link checker for EmDash that tells you what is broken before a customer does: a dead link in the menu, a page that shows an error, a map that will not load.

- **Broken links, grouped by how bad.** Every page (the site menu and footer), one page (a page that shows an error, or loads a map or form over an insecure connection), one link (a link inside a page that goes nowhere). One row per broken address, with every page it was found on.
- **Fix in one step.** Send visitors from a dead address on your site to a page you pick from a list, and the link is fixed everywhere it appears. Or open the page with the link named. Check any row again at once, or mark it as fine.
- **Links to other sites, checked politely.** A few at a time, never one site more than once a minute. A link is called broken only when the other website says the page is gone, twice, a day apart. Sites that turn away automatic checkers (LinkedIn, Instagram) are listed as "could not check", never as broken.
- **Email when it matters.** At once when a page shows an error or a menu link breaks, and a weekly list of only what is new. Several addresses, the site's name first in the subject, never more than one email a day of each kind.
- **A setup checklist** for whoever looks after the site: secure address, with and without www, the "page not found" page, search engines allowed in, scheduled tasks running, email working.
- **A dashboard widget** with the count.

No account, no key, nothing sent to anyone but the websites your pages link to. Editors see the links they can fix; page errors and setup are for Admins.
